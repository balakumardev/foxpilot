Automation Mode

Automation Mode lets the MCP server actively control web pages — clicking, typing, filling forms, navigating, taking page snapshots, running scripts, and inspecting console/network activity on any site. Enabling it grants the extension access to all websites at once, so the automation tools work without a per-site prompt. Leave it off unless you want full browser automation. Your domain deny list and per-tool toggles still apply.

Enable Automation Mode
Required for page-interaction tools (click, type, fill, navigate, snapshot, evaluate, console, network).

Connection Transport

WebSocket (default, recommended) or HTTP long-poll fallback for environments where WebSocket is unreliable. Changing this reloads the extension.

Input Realism (Anti-Detection)

Makes automated input look human (curved mouse movement, typing cadence). Does not change what actions do. "Off" reproduces the exact original instant behavior.
