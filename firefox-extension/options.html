Automation Mode
Master switch for page-control tools

Automation Mode lets the MCP server actively control web pages — clicking, typing, filling forms, navigating, taking snapshots, running scripts, and inspecting console/network activity on any site. Enabling it grants access to all websites at once. Your domain deny list and per-tool toggles still apply.

Enable Automation Mode

Connection & Input
Transport and anti-detection input behavior

WebSocket is the default. Use long-poll only where a persistent socket is unreliable. Changing this reloads the extension.

Input Realism · anti-detection

Makes automated input look human (curved mouse movement, typing cadence). Does not change what actions do. “Off” reproduces the exact instant behavior.
